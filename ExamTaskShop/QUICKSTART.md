# Быстрый старт - Интерактивное меню покупателя

## Требования

- PostgreSQL 13+ (запущен на порту 5432)
- C++20 компилятор
- libpqxx библиотека
- CMake 3.16+

## Установка и запуск (macOS)

### 1. Установка зависимостей

```bash
# Установка PostgreSQL
brew install postgresql@14
brew services start postgresql@14

# Установка libpqxx
brew install libpqxx

# Создание пользователя БД (если нужно)
psql postgres
CREATE USER postgres WITH PASSWORD '288288';
ALTER USER postgres CREATEDB;
\q
```

### 2. Сборка проекта

```bash
cd ExamTaskShop
mkdir build
cd build
cmake ..
cmake --build .
```

### 3. Первый запуск (инициализация БД)

```bash
# Запускаем демонстрационную программу для создания БД
./TaskExamShop
```

Эта программа автоматически:
- Создаст базу данных `online_store`
- Создаст все таблицы, процедуры, триггеры
- Заполнит тестовыми данными
- Создаст тестовых покупателей

### 4. Запуск интерактивного меню

```bash
# Запускаем интерактивное меню покупателя
./CustomerMenuApp
```

## Доступные тестовые пользователи

После инициализации в системе будут доступны:

- **ID: 1** - Иван Покупатель (★ PREMIUM статус, скидка 10%)
- **ID: 5** - Тестовый Покупатель (обычный статус)

## Функции меню покупателя

1. **Создать новый заказ** - Создание корзины
2. **Добавить товар в заказ** - Просмотр каталога и добавление товаров
3. **Удалить товар из заказа** - Управление корзиной
4. **Просмотр моих заказов** - История всех заказов
5. **Просмотр статуса заказа** - Детальная информация о заказе
6. **Оплатить заказ** - Выбор способа оплаты (паттерн Стратегия):
   - Банковская карта
   - Электронный кошелек (Яндекс.Деньги, QIWI, WebMoney)
   - СБП (Система Быстрых Платежей)
7. **Оформить возврат заказа** - Возврат completed заказов (до 30 дней)
8. **Просмотр истории статусов заказа** - Аудит изменений
9. **Выход**

## Бизнес-правила

### Оплата заказа
- **PREMIUM пользователи**: Автоматическая скидка 10% на все заказы
- **Обычные пользователи**: Стандартные цены
- Статус PREMIUM присваивается после 5 успешных заказов

### Возврат заказа
- ✓ Статус заказа должен быть `completed`
- ✓ Не более 30 дней с даты заказа
- ✗ Нельзя вернуть заказы в других статусах
- Товары автоматически возвращаются на склад

### Способы оплаты

#### 1. Банковская карта
- Номер карты: 16 цифр
- CVV: 3 цифры
- Срок действия: MM/YY

#### 2. Электронный кошелек
- Выбор типа: Яндекс.Деньги, QIWI, WebMoney
- ID кошелька: минимум 6 символов

#### 3. СБП
- Номер телефона: 11 цифр (начинается с 7 или 8)
- Выбор банка: Сбербанк, Тинькофф, Альфа-Банк, ВТБ и др.

## Безопасность

- Покупатель видит только **свои** заказы
- Все операции логируются в систему аудита
- SQL-инъекции предотвращены параметризованными запросами
- Автоматическая проверка прав доступа

## Примеры использования

### Сценарий 1: Оформление заказа

1. Запустить `./CustomerMenuApp`
2. Войти под пользователем (ID: 1)
3. Выбрать `1` - Создать новый заказ
4. Выбрать `2` - Добавить товар (например, Ноутбук x2)
5. Выбрать `6` - Оплатить заказ
6. Выбрать способ оплаты (например, Банковская карта)
7. Ввести данные карты
8. Заказ создан!

### Сценарий 2: Возврат заказа

1. Запустить `./CustomerMenuApp`
2. Войти под пользователем
3. Выбрать `4` - Просмотр моих заказов
4. Найти completed заказ
5. Выбрать `7` - Оформить возврат
6. Ввести номер заказа
7. Подтвердить возврат
8. Ввести причину
9. Возврат оформлен!

## Решение проблем

### Ошибка подключения к БД
```bash
# Проверить статус PostgreSQL
brew services list

# Перезапустить PostgreSQL
brew services restart postgresql@14

# Проверить подключение
psql -h localhost -p 5432 -U postgres -d postgres
```

### База данных не создана
```bash
# Запустить демонстрационную программу
./TaskExamShop
```

### Ошибка компиляции
```bash
# Очистить и пересобрать
cd build
rm -rf *
cmake ..
cmake --build .
```
